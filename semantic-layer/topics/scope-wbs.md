# Scope baseline and work breakdown structure

Topic ID: `SCOPE-WBS`

## Related concepts and aliases

work breakdown structure, decomposition, work package, WBS dictionary, scope baseline.

Search aliases: WBS, deliverable breakdown.

## When it matters

Use this when a deliverable is too large to estimate, assign or track as one piece.

## Practitioner guidance

Break deliverables into manageable work packages. Describe them in the WBS dictionary and check the decomposition against requirements before approving the scope baseline.

## PMP exam reasoning

The instructor calls out the work package as the lowest level in the WBS. Recognize the difference between decomposition and sequencing.

## Predictive, adaptive and hybrid relevance

Predictive work can use a scope baseline. Hybrid teams can apply it to defined deliverables while managing evolving work in a backlog. See the backlog topic for adaptive scope.

## Related project artifacts

Scope statement, WBS, WBS dictionary, Requirements traceability matrix.

## Common mistakes and distinctions

The WBS organizes deliverable scope. The schedule models activity sequence and timing.
