# Project or phase closure and formal acceptance

Topic ID: `CLOSE-FORMAL`

## Related concepts and aliases

project closure, phase closure, formal acceptance, stakeholder approval, archive.

Search aliases: project closeout, formal sign-off.

## When it matters

Use this when delivery seems finished but approval, archival or handoff is still open.

## Practitioner guidance

Review requirements and unresolved items with stakeholders, obtain and record formal acceptance where required, and archive records others will need. Check what remains before closing the phase or project.

## PMP exam reasoning

The instructor highlights determining what still needs to be done to obtain approval or close the project. Use the sequence and evidence already present in the scenario.

## Predictive, adaptive and hybrid relevance

An adaptive review can provide feedback or evidence. Confirm whether separate formal acceptance is required by governance, contracts or transition arrangements.

## Related project artifacts

Acceptance record, Closure report, Project archive.

## Common mistakes and distinctions

Internal completion is not stakeholder sign-off. Procurement closeout has a separate contract scope.
