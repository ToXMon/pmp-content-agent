# Baseline change control and backlog decisions

Topic ID: `CHANGE-CONTROL`

## Related concepts and aliases

change request, change control board, baseline change, impact assessment, integrated change control.

Search aliases: CCB, formal change control, change approval.

## When it matters

Use this when a request affects approved scope, dates, costs or contract commitments.

## Practitioner guidance

Record the request and evaluate impacts before seeking a decision from the appropriate authority. Keep a record of the decision and update approved plans if authorized. Route changes confined to evolving backlog work through the product owner's ordering process.

## PMP exam reasoning

The instructor compares predictive and adaptive ways of handling a request. Identify whether a baseline or a backlog is affected before choosing the next action.

## Predictive, adaptive and hybrid relevance

Predictive work uses formal control for approved baselines. Adaptive work uses backlog refinement within agreed boundaries. Hybrid needs both routes and a clear boundary.

## Related project artifacts

Change request, Change log, Product backlog, Approved baseline.

## Common mistakes and distinctions

A request is an input to a decision, not approval to implement. Product backlog ordering is not a substitute for contractual approval.
