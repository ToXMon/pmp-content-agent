# Ethics and professional conduct

Topic ID: `GOV-ETHICS`

## Related concepts and aliases

PMI Code of Ethics, responsibility, respect, fairness, honesty, mandatory standards.

Search aliases: professional ethics, ethical conduct.

## When it matters

Use the applicable ethics standard when project pressure conflicts with professional obligations.

## Practitioner guidance

Review the four values and distinguish mandatory standards from aspirational conduct. If the answer turns on a specific obligation, check the current Code and your applicable policies directly.

## PMP exam reasoning

The instructor calls attention to the Code and the mandatory standards for each value. The transcript is a study lead, not a substitute for the Code.

## Predictive, adaptive and hybrid relevance

Delivery approach does not change an ethical obligation. Tailor how you raise an issue to the applicable reporting channel.

## Related project artifacts

PMI Code of Ethics, Organizational policy.

## Common mistakes and distinctions

An ethics obligation is different from a preferred leadership style or a convenient business outcome.
