# Burnup, burndown and flow metrics

Topic ID: `MONITOR-FLOW`

## Related concepts and aliases

burnup chart, burndown chart, velocity, throughput, cumulative flow diagram, lead time, cycle time.

Search aliases: burn-up, burn-down, CFD, flow metrics, workflow stage, workflow bottleneck, tasks piling up.

## When it matters

Use this when a team needs to explain a release forecast or find where work is queuing.

## Practitioner guidance

Use burnup to compare completed work with total scope, burndown to see work remaining, and flow views to look for accumulation. Read a trend in context, especially when scope or the team changes.

## PMP exam reasoning

The instructor contrasts burnup with burndown and cautions learners to read which quantity the chart plots before interpreting it.

## Predictive, adaptive and hybrid relevance

Use these measures for adaptive teams or the adaptive workstream in hybrid. They can complement, rather than replace, milestone tracking.

## Related project artifacts

Burnup chart, Burndown chart, Cumulative flow diagram, Kanban board.

## Common mistakes and distinctions

Velocity and throughput use different units. A burndown change can reflect a scope adjustment rather than a change in completion rate.
