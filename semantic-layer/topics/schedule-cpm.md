# Critical path and schedule dependencies

Topic ID: `SCHEDULE-CPM`

## Related concepts and aliases

critical path, float, dependencies, network diagram, forward pass, backward pass.

Search aliases: CPM, critical path method, slack.

## When it matters

Use this when a date slips and you need to know which activities can move without delaying completion.

## Practitioner guidance

Build a network of dependencies with durations. Compare path lengths and calculate early and late dates to identify float. Recalculate as actual progress changes.

## PMP exam reasoning

The instructor emphasizes identifying the longest dependent path and determining float from early and late dates.

## Predictive, adaptive and hybrid relevance

Use on predictive schedules or the fixed dependency network within a hybrid project. An adaptive team's flow metrics answer different questions.

## Related project artifacts

Schedule network diagram, Project schedule.

## Common mistakes and distinctions

A long activity is not automatically critical. Look at its path through the network.
