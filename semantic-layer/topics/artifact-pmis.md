# Project artifacts, PMIS and configuration control

Topic ID: `ARTIFACT-PMIS`

## Related concepts and aliases

project management information system, configuration management, version control, project documents, management plans.

Search aliases: PMIS, artifact management system, controlled versions.

## When it matters

Use this when people cannot find the approved artifact, or multiple versions are in circulation.

## Practitioner guidance

Decide where plans and registers live, how people see the current approved version, and how to track changes. Use configuration controls for items that need version and change history.

## PMP exam reasoning

Session 5 emphasizes distinguishing the information system, artifact management and configuration management. The automatic transcript sometimes misrenders PMIS.

## Predictive, adaptive and hybrid relevance

Use appropriate controls in a predictive repository, an adaptive toolset or a shared hybrid workspace; keep authority and version history visible.

## Related project artifacts

Project management plan, Project registers, Configuration management plan, Artifact repository.

## Common mistakes and distinctions

A register tracks items such as risks or stakeholders. A management plan describes how to manage that work. Configuration control is a function, not simply a folder.
